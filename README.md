# Fanta — Animated Landing Page

A front-end study project I built by hand using HTML, CSS, and JavaScript to practice styling, visual composition, and scroll-driven animations.

The page features a Fanta-inspired design with vibrant gradients, layered images, and animated transitions across three sections.

## Features

- Scroll-driven animations powered by GSAP and ScrollTrigger.
- Product images, fruit, and leaves that move as you scroll.
- Coordinated changes in position, size, and rotation.
- Animated product cards featuring Coca-Cola, Fanta, and Pepsi.
- Custom typography, gradient backgrounds, and CSS Flexbox layouts.

## Technologies

- HTML5
- CSS3
- JavaScript
- GSAP
- ScrollTrigger

## What I Practiced

- Structuring a multi-section HTML page.
- Styling layouts with Flexbox and positioned elements.
- Creating depth through layered images and z-index.
- Building GSAP timelines to synchronize multiple animations.
- Connecting animation progress to scrolling with ScrollTrigger.

## Running the Project

Download or clone the repository and open `index.html` in your browser.

An internet connection is required to load GSAP and ScrollTrigger from the CDN.

## Purpose

This project demonstrates my learning and hands-on practice with front-end styling and animation. Navigation links and purchase buttons are visual demonstration elements.
